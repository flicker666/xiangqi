# 中国象棋 · 网页版

在 GitHub Pages 上直接玩的静态网页版中国象棋，无需安装、不用后端，手机浏览器打开即玩。

在线地址：https://flicker666.github.io/xiangqi/

## 玩法

- 点己方棋子选中，再点带绿点的格子走子；红圈表示可吃子。
- 人机对战：三档难度（入门 / 进阶 / 大师），可选择执红先行或执黑后行。
- 双人对弈：两人轮流在同一部手机上下棋。
- 悔棋：人机对局一次悔两步，双人对局悔一步。
- 背景音乐：WebAudio 程序合成的古风五声音阶循环旋律，可开关、调音量；走子 / 吃子 / 将军 / 胜负均有合成音效，无任何音频文件。
- 棋谱：本局着法自动记录（中文着法），可保存到浏览器 localStorage、查看历史、逐步复盘、导出文本。
- 残局：内置 8 个残局（单车胜单士、马炮胜单士、车马胜单车、双炮胜单象、马兵胜单士、车炮胜双士、单车胜双象、双马胜单车），红先行，将死黑将过关，限步数，带提示。

## 规则与 AI

- 完整规则：车马炮象士将、马腿、象眼、炮架、九宫、河界、卒过河横走、将帅不见面、将死 / 困毙；长打简化为同一方连续将军 3 次判负，同一局面出现 3 次判和。
- AI：Negamax + Alpha-Beta + 迭代加深 + 子力 / 位置分评估 + 吃子杀棋搜索；入门深度 2 / 0.6 秒，进阶深度 3 / 1.5 秒，大师深度 4 / 3 秒；分层用 `setTimeout` 分步计算，不卡界面。

## 文件

- `index.html` — 页面结构与棋盘 SVG
- `style.css` — 样式（手机竖屏自适应）
- `xiangqi.js` — 规则引擎 + AI + 音频 + 界面（引擎部分可在 Node 下测试）
- `test-rules.js` — 规则测试（`node test-rules.js`，30 项）

## 本地运行

直接用浏览器打开 `index.html` 即可；或在目录下跑 `python3 -m http.server` 后访问。

## 与 iOS 版的关系

仓库 `main` 分支是 SwiftUI iPhone App 源码；本分支（`gh-pages`）是单独的网页版，两者规则与 AI 逻辑一致，但代码不共享——GitHub Pages 只能托管静态网页，跑不了 Swift。
